Documentation

Complete guide to using the Chat AI feature

🚀 Quick Start Guide

💬 Chat AI

  1. Click "Get Started" or navigate to Chat AI
  2. Sign in or continue as guest
  3. Type your question or prompt
  4. Receive instant AI-powered responses
  5. Use voice input, attach files, or upload images

💬 Chat AI Features

AI Models

  • GPT-4o: Most capable model for complex reasoning
  • GPT-4o Mini: Faster, efficient for simple tasks
  • Claude 3.7 Sonnet: Best for writing and analysis
  • Llama 3.2 (Free): Free tier, great for general use

Input Methods

  • 📝 Text Input: Type your questions naturally
  • 🎤 Voice Input: Click microphone icon to speak
  • 🖼️ Image Upload: Attach images for analysis
  • 📎 File Attachment: Upload documents for processing

Chat Management

  • ➕ New Chat: Start fresh conversation
  • 💾 Save History: Auto-saved for logged-in users
  • 📥 Export Chat: Download conversations as text/JSON
  • 🔍 Search: Find specific chats or messages
  • 🗑️ Delete: Clear individual conversations

Code Features

  • Syntax highlighting for all major languages
  • Copy code with one click
  • Supports Python, JavaScript, Java, C++, and more
  • Markdown rendering for formatted responses

⚙️ Settings & Customization

API Configuration

  • Add your own OpenRouter API key
  • Select preferred AI model
  • Settings automatically saved

Theme Options

  • Blue & Black (Default)
  • Purple & Black
  • Green & Black

📊 Technical Architecture

Frontend: HTML5, CSS3, Vanilla JavaScript

Backend: Python, Flask, MongoDB

AI API: OpenRouter (GPT-4o, Claude, Llama)

Code Highlighting: Highlight.js

Markdown: Marked.js

Text-to-Speech: Web Speech API

Database: MongoDB for users, history, analytics

🔒 User Accounts

Registered Users

  • Persistent chat history across devices
  • Save and organize conversations
  • Personalized preferences
  • Usage analytics and insights

Guest Mode

  • Try features without signing up
  • Temporary session storage
  • Full access to both AI tools
  • History cleared on browser close

🔧 System Requirements

  • 🌐 Modern web browser (Chrome, Firefox, Edge, Safari)
  • 📡 Active internet connection for AI features
  • ⚡ JavaScript enabled
  • 📦 Minimum 2GB RAM recommended
  • 📱 Responsive design works on mobile & tablet

❓ Troubleshooting

Common Issues

AI not responding: Check internet connection, verify API key in settings

Audio not playing: Enable audio in browser, check system volume

Chat history lost: Sign in to save permanently (guest mode is temporary)

Code not highlighting: Refresh page, check JavaScript is enabled

🎯 Best Practices

  • 📝 Be specific in your prompts for better responses
  • 💾 Create an account to save your work
  • 🔑 Use your own API key for unlimited access
  • 📊 Choose the right model for your task
  • 💬 Use Chat AI for conversations and code
