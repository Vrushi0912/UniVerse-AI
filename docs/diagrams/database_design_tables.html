UniVerse AI - Database Schema Design

1. Users Collection

Collection: users
Field Name Data Type Description
_id ObjectId Primary key (auto-generated)
email String User email (unique, indexed)
password_hash String BCrypt hashed password
full_name String User's full name
subscription_tier String free, pro, business
is_active Boolean Account status
preferences Object Embedded user preferences
oauth_provider String OAuth provider (google), if applicable
created_at DateTime Account creation timestamp
last_login DateTime Last login timestamp

2. Chat History Collection

Collection: chat_history
Field Name Data Type Description
_id ObjectId Primary key
user_id ObjectId Reference to users collection
session_id String Unique session identifier
title String Chat title
model_used String Main model used for session
messages Array List of message objects
messages.role String user or assistant
messages.content String Message text content
messages.timestamp DateTime Message timestamp
messages.tokens_used Integer Token usage per message
total_tokens Integer Total tokens used in session
is_archived Boolean Archive status
created_at DateTime Session creation time
updated_at DateTime Last update time

3. Educational Content Collection

Collection: educational_content
Field Name Data Type Description
_id ObjectId Primary key
user_id ObjectId Reference to users collection
topic String Content topic/title
content String Generated textual content
diagram_data String Mermaid diagram definition
audio_script String Text-to-speech script
rating Integer User rating (1-5)
is_favorite Boolean Favorite status
tags Array[String] Organization tags
created_at DateTime Creation timestamp

4. Saved Prompts Collection

Collection: saved_prompts
Field Name Data Type Description
_id ObjectId Primary key
user_id ObjectId Reference to users collection
title String Prompt title
content String Prompt text content
description String Optional description
category String Category (default: general)
tags Array[String] Searchable tags
is_favorite Boolean Favorite status
is_public Boolean Public visibility flag
model_preference String Preferred AI model
temperature Float Generation temperature (0.0-2.0)
usage_count Integer Usage counter
created_at DateTime Creation timestamp
updated_at DateTime Last update timestamp
last_used_at DateTime Last usage timestamp

5. User Preferences Collection

Collection: user_preferences
Field Name Data Type Description
_id ObjectId Primary key
user_id ObjectId Reference to users (unique)
api_keys Object Encrypted API key configuration
theme Object Theme settings
theme.mode String light, dark, auto
theme.primary_color String UI accent color
model Object Model default settings
model.default_model String Default model ID
ui Object UI behavior settings
ui.compact_mode Boolean Compact layout flag
ui.language String Interface language (e.g., en)
custom_settings Object Flexible custom settings
created_at DateTime Creation timestamp
updated_at DateTime Last update timestamp

6. Sessions Collection

Collection: sessions
Field Name Data Type Description
_id ObjectId Primary key
user_id ObjectId Reference to users
session_token String JWT token or Session ID
expires_at DateTime Expiration timestamp
is_active Boolean Active status
ip_address String Client IP address
device_info String User agent / Device info
created_at DateTime Creation timestamp
