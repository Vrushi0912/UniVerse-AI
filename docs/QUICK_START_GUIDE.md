# 🚀 Quick Start Guide - Save Prompt System

## Get Started in 3 Minutes

---

## Step 1: Open Chat Page

Navigate to `chat.html` in your browser.

---

## Step 2: Have a Conversation

Ask the AI a question, for example:
```
"Explain how JavaScript promises work"
```

Wait for the AI to respond.

---

## Step 3: Save the Conversation

Click one of these buttons:
- **💾 Save button** in the input area (bottom right)
- **💾 Save to Library** in the header

You'll see a confirmation toast: "💾 Prompt saved to library!"

---

## Step 4: View Your Library

### Option A: Click the prompt
A popup will appear asking "View in Library?"
- Click "Go to Library"

### Option B: Manual navigation
- Click "📚 Library" in the sidebar or navigation menu

---

## Step 5: Explore Your Saved Prompts

In the library you can:

### Search
Type keywords in the search box to find specific prompts

### Filter
- Select a category (Programming, Explanation, etc.)
- Toggle "⭐ Favorites" to see only favorites
- Sort by date, views, or alphabetically

### Interact with Cards
- **Click card** - View full details
- **Click ⭐** - Mark as favorite
- **Click 📋** - Copy to clipboard
- **Click 📥** - Export as JSON
- **Click 🗑️** - Delete prompt

---

## Key Features

### 💾 Auto-Save
Every saved prompt includes:
- Your exact question
- AI's complete response  
- Timestamp
- AI model used
- Auto-generated tags and category

### 🔍 Instant Search
- Search across prompts, responses, and tags
- Results update as you type
- No page reloads needed

### ⭐ Favorites
- Mark important prompts as favorites
- Quick filter to show only favorites
- Gold star indicates favorite status

### 📊 Statistics
View at the top of library:
- Total saved prompts
- Number of favorites
- Total view count

### 💡 AI Suggestions
While typing in chat:
- After 3+ words, system shows similar saved prompts
- Click any suggestion to view full details
- Helps you reuse past answers

## Tips & Tricks

### 🎯 Best Practices

1. **Save Valuable Responses**
   Only save prompts you'll want to reference later

2. **Use Favorites**
   Star your most important or useful prompts

3. **Search Smart**
   Use specific keywords for faster results

4. **Export Regularly**
   Use "📥 Export All" to backup your library

5. **Clean Up**
   Delete outdated or duplicate prompts

### ⚡ Keyboard Shortcuts

In Library:
- `Ctrl/Cmd + F` - Focus search box
- `Escape` - Close modal

In Chat:
- `Ctrl/Cmd + K` - New chat
- `Escape` - Close any modal

---

## Troubleshooting

### Issue: Save button does nothing
**Solution**: Make sure you have a complete conversation (user message + AI response)

### Issue: Library is empty
**Solution**: 
1. Check if you saved any prompts
2. Clear any active filters
3. Check browser console for errors

### Issue: Search not working
**Solution**:
1. Clear search box and try again
2. Check if filters are too restrictive
3. Refresh the page

### Issue: Can't see saved prompts in chat sidebar
**Solution**: Refresh the chat page after saving
